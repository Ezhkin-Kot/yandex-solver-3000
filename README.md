# yandex-solver-3000

Автоматически проходит теоретические уроки на practicum.yandex.ru: раскрывает
диалоговые блоки урока, переходит к следующему уроку по готовности, и (в
YOLO-режиме) отвечает на квизы, выбирая случайный вариант.

Работает через [WebDriver](https://www.w3.org/TR/webdriver1/) поверх
`geckodriver`, управляя настоящим окном Zen или Firefox — используется твоя
реальная (залогиненная) сессия в отдельном, выделенном под бота профиле
браузера.

## Требования

- Rust (стабильный тулчейн, `cargo`)
- [`geckodriver`](https://github.com/mozilla/geckodriver) в `PATH`
- Zen Browser или Firefox

### macOS

```bash
brew install geckodriver
```

Zen/Firefox предполагаются установленными обычным образом
(`/Applications/Zen.app`, `/Applications/Firefox.app`) — путь определяется
автоматически.

### Linux

Поставь `geckodriver` через пакетный менеджер дистрибутива или скачай бинарник
из [релизов проекта](https://github.com/mozilla/geckodriver/releases) и положи
в `PATH`. Браузер (`zen`/`firefox`) должен быть доступен по имени команды в
`PATH` — так его находит и сама программа, и `geckodriver`.

## Сборка

```bash
cargo build --release
```

Бинарник: `target/release/yandex-solver-3000`.

## Запуск

```bash
./target/release/yandex-solver-3000
```

Откроется окно браузера с отдельным профилем для бота. Один раз залогинься в
Яндекс ID в этом окне — профиль сохранится, при следующих запусках логиниться
заново не нужно. Как только окажешься на странице урока, бот сам начнёт
нажимать нужные кнопки. Останавливается по `Ctrl+C` — окно браузера и
`geckodriver` закрываются автоматически.

## Настройка

Все параметры — через переменные окружения или файл `.env` в рабочей папке
(скопируй `.env.example`):

```bash
cp .env.example .env
```

| Переменная            | По умолчанию                                       | Описание                                                               |
| --------------------- | -------------------------------------------------- | ---------------------------------------------------------------------- |
| `BROWSER`             | `zen`                                              | `zen` или `firefox`                                                    |
| `BROWSER_BINARY_PATH` | macOS: путь к `.app`; Linux: имя команды из `PATH` | Явный путь к бинарнику браузера                                        |
| `BROWSER_PROFILE_DIR` | `~/.zen-bot-profile` / `~/.firefox-bot-profile`    | Папка выделенного профиля браузера                                     |
| `GECKODRIVER_PORT`    | `4445`                                             | Порт, на котором поднимается `geckodriver`                             |
| `YOLO_MODE`           | выключен                                           | `1`/`true`/`yes` — отвечать на квизы автоматически (случайный вариант) |

Переменная окружения всегда имеет приоритет над значением из `.env`.

## Диагностика

**`binary is not a Firefox executable`** — эту ошибку выдаёт сам
`geckodriver`, не наша программа. Она означает, что путь в
`BROWSER_BINARY_PATH` (или найденный по умолчанию) указывает на
обёртку/симлинк, а не на настоящий исполняемый файл браузера — `geckodriver`
ищет метаданные приложения (`application.ini`) рядом с бинарником, а они
лежат рядом только с настоящим файлом внутри папки установки. Особенно часто
встречается на Linux, где команда вроде `zen-browser` в `PATH` — это
launcher-скрипт, а не сам браузер.

Проверить:

```bash
file "$(which zen-browser)"   # ELF executable — ок; shell script — это обёртка
```

Найти настоящий бинарник:

```bash
find / -maxdepth 6 -iname "application.ini" 2>/dev/null | grep -i zen
```

и указать путь к исполняемому файлу рядом с найденным `application.ini` в
`BROWSER_BINARY_PATH`.

## Ограничения

- Понимает только тот тип уроков, что построен на диалоговых блоках
  (`theory-viewer__block_type_*`) — раскрытие реплик, переход к следующему
  уроку, квизы с выбором варианта (radio/checkbox).
- Незнакомый тип блока (код-задание и т.п.) — бот останавливает клики и ждёт,
  пока ты не решишь его вручную; работа продолжится автоматически, как только
  на странице снова появится знакомая кнопка.
- `YOLO_MODE` отвечает на квизы **наугад** — годится только если цель
  формально пройти урок, а не реально усвоить материал.
